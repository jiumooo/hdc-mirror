## 一、当前可验证的功能

### 1. 设备发现与信息

| 能力 | 状态 | 验证方式 |
| --- | --- | --- |
| 扫描局域网 hdc 设备 | 可用 | 点「扫描」，约 11 秒出结果 |

### 3. 音频

PC 端以蓝牙 A2DP Sink 身份接收手机音频（`Windows.Media.Audio.AudioPlaybackConnection`），声音走系统默认播放设备。
- 前置条件：手机与电脑已配对；手机控制中心把音频输出切到「电脑」。
- 首次 Open 约需 30 秒（系统 API 内部超时），之后复用。
- 应用拿不到 PCM，音画同步只能靠固定缓冲，不能采样级对齐。

### 4. 设置

| 分组 | 项 |
| --- | --- |
| 画质 | 帧率上限 30/60、码率 4/8/16/24 Mbps（下次连接生效） |
| 行为 | 关闭窗口时最小化到托盘 |
| 音频 | 连接设备后自动开启音频 |

设置落在 `%LOCALAPPDATA%\HdcMirror\settings.json`，改动即存。

### 5. 托盘

左键单击显示/隐藏主窗口；右键六项：显示主窗口 / 设备管理 / 基本设置 / 检查更新 / 关于 / 完全退出。

### 6. 软件内更新

`Services\UpdateService.cs` 查 GitHub Releases 最新版本，与程序集版本比较：
- 有新版本 → 提示，确认后下载 `Setup.exe` 并启动安装，随后退出程序；
- 已最新 / 未配置 / 404 / 断网 → 静默写日志，只有手动点「检查更新」才在状态栏给一句反馈。

**尚缺一步**：`UpdateService.RepoOwner` 现在是占位符 `OWNER`，仓库地址定下来后改这一个常量即可（`IsConfigured` 会自动从 false 变 true）。发版时把安装包作为 Release 附件上传。

## 三、操作者验收步骤（建议顺序）

1. 启动 `HdcMirror.exe`，确认主窗口按手机比例显示、无崩溃。
2. 点「扫描」→ 选中设备 → 点「连接」→ 手机窗口出现画面。
3. 拖边改大小、拖到屏幕边缘，确认不越界且比例不变。
4. 手机横过来，确认手机窗口自动转成横向、控制条到右侧。
5. 在手机窗口里点开一个输入框，用电脑键盘打字（含中文），确认能上屏。
6. 试 Esc / Ctrl+H / Ctrl+J / Ctrl+P / Ctrl+↑↓。
7. 点控制条音频按钮，手机控制中心切到「电脑」，确认声音从电脑出。
8. 手机侧关掉无线调试再打开，确认画面自动恢复。
9. 托盘右键六项逐个点一次。
10. 设置 → 通用设置改码率，回来重新连接，看日志 `-bitRate` 是否变化。

## 五、已知限制

- 锁屏状态下投屏为黑屏（系统安全窗口保护），需先解锁。
- 设备侧 daemon 约 9 分钟会被断开一次，靠自动重连恢复。
- 音频接管后手机自身的通话、铃声仍走手机。
- 无线调试端口是随机高位端口，靠 `endpoints.json` 线索而不是端口扫描。
