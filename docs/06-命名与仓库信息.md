## 3. 推荐目录结构

```
hdc-mirror/
├─ src/
│  ├─ HdcMirror.Core/            # net8.0 类库，零 UI 依赖
│  │  ├─ Scrcpy/                 # gRPC onStart 流、wire 解析、SPS 解析、帧重组
│  │  ├─ Hdc/                    # hdc 进程封装、fport、daemon 生命周期、so 变体选择
│  │  ├─ Input/                  # 离散动作构造、串行队列、节流、坐标映射
│  │  ├─ Devices/                # DeviceStore：多设备卡片记录与持久化
│  │  └─ Settings/               # SettingsStore、AvSyncMode 等枚举与默认值
│  ├─ HdcMirror.Decode/          # net8.0：Media Foundation 解码 + D3D 纹理，FFmpeg 回退
│  └─ HdcMirror.App/             # net8.0-windows，WPF 外壳
│     ├─ Views/                  # 主窗口、连接窗口、设置页、关于页
│     ├─ ViewModels/
│     ├─ Resources/              # Strings.Ui.resx / Strings.Errors.resx（zh-CN 默认）
│     └─ Assets/                 # 图标、字体（Segoe Fluent Icons 不打包，引用系统）
├─ docs/                         # 01~06 系列文档（含本文）
│  └─ reference/                 # 只读外部参考（jar 内 so、协议说明），不入库
├─ samples/                      # 只入库 extradata.bin（SPS+PPS）；h264 与截图属真实屏幕内容，仅存本机
├─ tools/                        # 构建与诊断脚本（publish.ps1、probe 脚本）
├─ .gitignore
├─ HdcMirror.sln
├─ README.md
├─ CHANGELOG.md
└─ LICENSE
```

### 3.1 `.gitignore` 要点

| 规则 | 原因 |
|---|---|
| `bin/` `obj/` `.vs/` `*.user` `*.suo` | 构建产物与本地 IDE 状态 |
| `publish/` `releases/` `*.nupkg` `dist/` | 打包输出，走 GitHub Releases 不入库 |
| `*.bak` `*.orig` `*.tmp` `~$*` | 编辑残留 |
| `_probe/` `.scratch/` `logs/` `*.log` | 一次性探针与运行日志 |
| `docs/reference/` | jar 内提取的 so/jar 属第三方二进制，不入库 |
| `tools/hdc.exe` `tools/*.jar` | 第三方可执行文件，由用户本机 `.hnscrcpy` 提供，不入库 |
| `samples/*.h264` `samples/*.mp4` `samples/*.jpeg` `samples/*.png` `samples/*.gif` | 真实屏幕内容（含第三方 App 界面与用户浏览记录），一律不入库 |
| `.DS_Store` `Thumbs.db` | 跨平台噪声 |

> **只有 `samples/extradata.bin`（32 B，SPS+PPS）允许入库** —— 它是解码回归所需的最小协议头，不含画面。
> `samples/full.h264`（真实屏幕码流）与任何截图 **不得入库**，只留在本机；`.gitignore` 已按 `samples/*.h264`、`samples/*.jpeg` 等规则排除。
> 需要图片类回归素材时，用合成画面（纯色块 / 彩条）本地生成后人工确认无隐私，再写入 `tools/samples-allowlist.txt`。

## 4. 命名空间与程序集约定

| 程序集 | 目标框架 | 根命名空间 | 允许依赖 |
|---|---|---|---|
| `HdcMirror.Core` | `net8.0` | `HdcMirror.Core` | `Grpc.Net.Client`、`System.Text.Json`、BCL；**不得**引用 WPF |
| `HdcMirror.Decode` | `net8.0` | `HdcMirror.Decode` | `HdcMirror.Core`、`Vortice.*`/`FFmpeg.AutoGen`；**不得**引用 WPF |
| `HdcMirror.App` | `net8.0-windows` | `HdcMirror.App` | `HdcMirror.Core`、`HdcMirror.Decode`、`WPF-UI`、`Serilog`、`Velopack` |

### 4.1 命名空间落点（文件夹即命名空间，一一对应）

| 目录 | 命名空间 |
|---|---|
| `src/HdcMirror.Core/Scrcpy` | `HdcMirror.Core.Scrcpy` |
| `src/HdcMirror.Core/Hdc` | `HdcMirror.Core.Hdc` |
| `src/HdcMirror.Core/Input` | `HdcMirror.Core.Input` |
| `src/HdcMirror.Core/Devices` | `HdcMirror.Core.Devices` |
| `src/HdcMirror.Core/Settings` | `HdcMirror.Core.Settings` |
| `src/HdcMirror.Decode/MediaFoundation` | `HdcMirror.Decode.MediaFoundation` |
| `src/HdcMirror.App/Views` | `HdcMirror.App.Views` |
| `src/HdcMirror.App/ViewModels` | `HdcMirror.App.ViewModels` |
| `src/HdcMirror.App/Resources` | `HdcMirror.App.Resources`（资源类 `Strings.Ui` / `Strings.Errors`） |

### 4.2 命名硬规则

1. 程序集名 = 根命名空间，**不带** `.Windows`、`.Wpf`、`.Client` 之类后缀；
2. 类型名不重复程序集名（不要出现 `HdcMirror.Core.Core`）；
3. 协议相关类型统一加 `Scrcpy` 前缀（`ScrcpyClient`、`ScrcpyFrame`、`ScrcpySps`），hdc 相关统一进 `Hdc/`（`HdcRunner`、`HdcPortForwarder`、`ScrcpyDaemon` 属 Hdc 域）；
4. 音画策略枚举固定为 `HdcMirror.Core.Settings.AvSyncMode { Auto, ForceSync, ForceLowLatency }`，默认 `Auto`；
5. 资源键前缀固定七类（M0 已落实，键名以本节为准）：
   `App_`（应用级：标题、名称、版本格式）、`Nav_`（导航与页面标题/说明）、`Ui_`（界面通用按钮与动词）、
   `Status_`（状态栏与提示）、`Tray_`（托盘与右键菜单）、`Err_`（错误消息）、`Upd_`（更新流程）；
6. 全局禁用 `HnCast` 字样（含注释、日志标签、临时文件名）。

## 5. 版本号规则

格式 `MAJOR.MINOR.PATCH`，**0.x.y 阶段**：

| 规则 | 说明 |
|---|---|
| 起点 | `0.1.0`（M0 骨架可装） |
| 里程碑推进 | 每完成一个 M 里程碑，**MINOR +1、PATCH 归零**：M0→`0.1.0`、M1→`0.2.0`、M2→`0.3.0`、M3→`0.4.0`、M4→`0.5.0`、M5→`0.6.0`、M6→`0.7.0` |
| 里程碑内修复 | **PATCH +1**：`0.5.1`、`0.5.2`…（只修 bug / 文案 / 资源键，不加功能） |
| 功能增量（非里程碑） | **MINOR +1**：`0.8.0` |
| 首个对外正式版 | M6 出口达标后 `1.0.0`；`1.0.0` 之前一律标注 **Pre-release** |
| 破坏性变更 | 0.x 阶段允许在 MINOR 内做；1.0.0 之后必须 MAJOR +1 |
| Tag 格式 | `v0.5.0`（带前缀 `v`，与 Velopack 的 `--version` 参数一致，不带 `v`：`vpk upload --version 0.5.0`） |
| 版本号唯一来源 | `Directory.Build.props` 里的 `<Version>`；**禁止**在 csproj、AssemblyInfo、安装包脚本里各写一份（发版脚本漏改 TAG 已在同类项目上出过事故） |
| CHANGELOG | `CHANGELOG.md` 按 `## [0.5.0] - YYYY-MM-DD` 分节，只写"当前是什么"，不写历史演进叙述 |

## 9. 对外名称禁止带 App 后缀（2026-11-11 用户要求）

- 软件对外的名称、可执行文件名、安装包名、窗口标题、托盘名称、README 标题，**一律不得出现 App / APP 后缀**。
- 正确：HdcMirror、HdcMirror.exe、鸿蒙手机无线控制。
- 错误：HdcMirror.App、HdcMirrorApp、HdcMirror APP。
- 内部程序集/命名空间可按工程结构划分（HdcMirror.Core / HdcMirror.Decode），但**可执行产物**必须是 HdcMirror.exe（AssemblyName = HdcMirror）。
