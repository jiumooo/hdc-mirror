# 鸿蒙手机无线控制 · HdcMirror

在 Windows 上实时镜像并操控 HarmonyOS NEXT 手机。手机端**零安装**，只用系统自带的 hdc 无线调试。

当前版本 **0.2.3** · Windows 10/11 · .NET 8 桌面运行时

---

## 一、这是什么

一个自用的桌面客户端：把手机画面拉到电脑窗口里，用鼠标键盘直接操作，并把手机声音接到电脑音箱。

手机侧不装任何 App —— 画面来自设备自带的投屏服务，输入走系统自带的 `uitest uiInput`，音频走蓝牙 A2DP，全部由电脑这一端发起。

## 二、功能一览

| 分类 | 能力 |
| --- | --- |
| 画面 | 实时镜像、横竖屏自动切换、等比缩放不裁切、左右黑边自动去除、全屏、窗口置顶 |
| 操作 | 单击 / 长按 / 拖拽 / 滚动、返回·主桌面·多任务、按键映射（自己定义，不给预设） |
| 音频 | 手机声音接到电脑（蓝牙 A2DP）、可选输出设备、连接后自动开启 |
| 设备 | 局域网扫描（含换端口后的深度扫描）、多设备记忆、记住名字、忘记设备、USB 直连 |
| 其它 | 中英双语、断线自动重连、应用内检查更新、托盘常驻、单实例 |

## 三、环境要求

- **电脑**：Windows 10 2004 及以上（音频接收需要 10.0.19041 以上）、.NET 8 桌面运行时
- **手机**：HarmonyOS NEXT 5.0.0（API 12）及以上，开启「无线调试」（开发者选项里），与电脑在同一局域网；已在 OpenHarmony 7.0.0.111（API 26）真机实测
- 蓝牙音频：电脑与手机先完成一次蓝牙配对

## 四、安装

安装包有两个，按机器情况选一个双击即可（`<版本>` 是当前版本号，例如 `0.2.3`）：

| 安装包 | 大小 | 前提 | 适合谁 |
| --- | --- | --- | --- |
| **`HdcMirror-Setup-<版本>.exe`** | **26.5 MB** | **电脑已装 .NET 8 桌面运行时** | 已装 .NET 的机器；体积最小、启动最快 |
| **`HdcMirror-Setup-Full-<版本>.exe`** | **82.2 MB** | 无（内置官方 .NET 8 桌面运行时 55.7 MB） | 没装 .NET、也不想自己去下：双击即用 |

> ⚠️ `HdcMirror-Setup-<版本>.exe` 本身是 .NET 程序：机器上没有 .NET 8 桌面运行时，双击会提示缺少运行时、打不开。不确定就下 82.2 MB 的完整版。
> 完整版把官方运行时安装器一起打进包里：先查本机有没有 .NET 8 桌面运行时，缺才静默安装（需一次 UAC 管理员确认），装完立刻弹出同一个安装界面。

两个安装包的界面、校验、卸载方式完全一致。
安装界面里可以：

- 选界面语言（简体中文 / English），整个界面跟着切换
- 阅读《用户说明与免责声明》，勾选同意后才能点「安装」
- 改安装位置：默认 `C:\HdcMirror`，可以直接改盘符（例如改成 `D:\Programs`），也能点「浏览…」选目录

安装路径会做校验，以下情况安装按钮直接置灰并说明原因：磁盘根、`Windows`、`Program Files`、`%LOCALAPPDATA%`、`%APPDATA%`、`%TEMP%`、用户目录本身、超过 170 字符的路径、目标目录非空且不是本程序、无写入权限。

程序会自动在你选的目录下补 `HdcMirror` 子文件夹：填 `D:\Programs` → 实际装到 `D:\Programs\HdcMirror`。

想完全静默（脚本/批量部署，同样受上述校验约束）：

```
HdcMirror-Setup-<版本>.exe --installto "D:\Programs\HdcMirror" --silent
```

> 安装界面由本项目自带（`src/HdcMirror.Installer`），内嵌官方 Velopack 安装载荷；`HdcMirror-win-Setup.exe` 保留给脚本与更新流程使用。
> 两个安装包由 `tools\pack\build-installers.ps1` 一次生成，文件名自动带当前版本号。

### 缺运行时会怎样

安装包自带检测：缺 .NET 8 桌面运行时，会弹窗问是否下载安装，点「是」后同一次安装继续。离线/内网机器可先跑 `HdcMirror-preinstall-check.cmd` 自查缺什么、去哪儿下载。

## 五、卸载

安装目录根里有 **`卸载 HdcMirror.exe`**（独立程序，不经过命令行）。双击后：

1. 弹确认框，列出将删除的内容（程序本体、快捷方式、安装目录下的 `data\`、注册表项 `HKCU\Software\HdcMirror`），默认停在「否」
2. 点「是」后是一个进度窗口，逐步显示：结束进程 → 调起 Velopack 卸载 → 等它清目录 → 清理安装目录 → 清注册表 → 清快捷方式
3. 结束时报告结果；若仍有残留会逐条列出

安全校验（不满足就拒绝运行，一个文件都不删）：安装根只从「EXE 所在目录」或注册表 `InstallLocation` 取；目录名必须是 `HdcMirror`；必须有 `Update.exe` 与 `HdcMirror.exe`；且不能是 `%LOCALAPPDATA%`、`%APPDATA%`、用户目录、`Windows`、`Program Files`、`%TEMP%` 本身。

## 六、连接手机

1. 手机：设置 → 系统 → 开发者选项 → 打开「无线调试」
2. 电脑：打开 HdcMirror → 点「扫描」
3. 设备出现在下拉里后点它 → 点「连接」

扫描不到时：手机换过端口是常见原因，程序会先常规扫描，再对该设备做深度端口扫描（状态栏会显示进度）。仍未找到，去「设置 → 设备管理」手动填 IP 与端口。

USB 直连同样可用：插上线，设备列表里会以序列号出现，标记为「有线」。

## 八、画面与音频

**画质**：设置 → 画面，四档预设（超清 24 Mbps / 高清 16 / 均衡 8 / 流畅 4+30Hz），也可单独调帧率与码率；两者联动，手动改动会显示为「自定义」。帧率「自动」表示跟随手机当前刷新率。

**黑边**：横屏视频两侧留黑时自动横向拉伸填满，不动上下；窗口始终保持手机比例，超出桌面会自动整块搬回屏幕内。

**音频**：设置 → 音频，点「开始接收」后，手机声音从电脑输出；连接设备后自动开启可勾选。输出设备可选（接收期间临时切到该设备，停止接收还原原默认设备）。

- 手机控制中心「投射音频」里也能看到这台电脑，选中同样生效
- 手机侧音量提供 0/100 两档是蓝牙接收端能力限制，不是软件问题，中间音量用电脑侧调

## 十、数据存放

**全部在安装目录下**：`<安装根>\data`

```
<安装根>\              例：C:\HdcMirror 或 D:\Programs\HdcMirror
├─ current\            程序本体（升级时整体替换）
├─ packages\           安装包缓存
├─ Update.exe          Velopack 更新器
├─ 卸载 HdcMirror.exe  卸载入口
└─ data\               用户数据
   ├─ settings.json    设置
   ├─ devices.json     记住的设备
   ├─ endpoints.json   端口线索（换端口后仍能找到）
   ├─ lockscreen.png   锁屏画面缓存
   └─ logs\            运行日志（按天）
```

- **升级**：只替换 `current\`，`data\` 保留
- **卸载**：安装目录整体删除，数据一并清掉
- 从旧版本（数据在 `%APPDATA%\HdcMirror`）升级时，首次启动会把设置、设备、日志搬过来，只补缺不覆盖

## 十一、仓库结构

```

  HdcMirror.Core/        设备、投屏通道、输入通道、设置与数据路径
  HdcMirror.Decode/      H.264 解码（FFmpeg 绑定）
  HdcMirror.App/         WPF 界面、镜像窗、音频、更新

docs/                    设计文档与缺陷记录
```

## 十二、从源码构建

```powershell
C:\dotnet8\dotnet.exe build src\HdcMirror.sln -c Debug
C:\dotnet8\dotnet.exe run --project src\HdcMirror.SelfTest\HdcMirror.SelfTest.csproj
powershell -File tools\pack\build-release.ps1          # 出 Velopack 载荷与升级包
C:\dotnet8\dotnet.exe publish src\HdcMirror.Uninstaller\HdcMirror.Uninstaller.csproj -c Release -o src\HdcMirror.Uninstaller\publish
powershell -File tools\pack\build-installers.ps1       # 出两个安装包（名字自动带版本号）
```

> 顺序不能反：`build-installers.ps1` 要把 `build-release.ps1` 产出的 `HdcMirror-win-Setup.exe` 嵌进安装器里。

## 十三、常见问题

**扫不到手机**：确认手机与电脑同网段、无线调试开着；换过端口时等深度扫描跑完；仍不行在「设备管理」手填。

**点了没反应**：确认镜像窗是前台窗口、手机未锁屏（锁屏界面不接受注入）。

**没有声音**：先点控制条喇叭开启接收；手机控制中心里选这台电脑；确认蓝牙已配对。

**音频有延迟**：蓝牙 A2DP 本身有 100~300ms，属链路限制。

**窗口拖出屏幕**：松开即自动弹回桌面内并保持手机比例。

**界面卡「未响应」**：拖边框过快的旧问题已修（尺寸变更去抖），如仍出现，日志在 `data\logs`。

## 十五、隐私与免责

**收集什么**：不收集。无遥测、无统计、无账号、无云端。

**网络访问**：仅两类 —— 与本机手机之间的 hdc / 投屏通道（局域网或 USB），以及检查更新时访问 GitHub Release。

**数据落在哪**：全部在安装目录下的 `data\`，见第十节；卸载即清除。

**免责**：本项目为个人自用工具，与华为无隶属关系，未获其授权或认可。投屏与输入依赖手机系统自带的调试服务，系统更新可能使其失效。使用风险自负；如相关方有异议，将立即停止分发。
